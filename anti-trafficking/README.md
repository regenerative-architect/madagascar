# Madagascar — Protection × Regeneration × Responsible Finance

**Public-interest HTML toolkit, 27 October 2026 · Foster + Navi / Planetary Restoration Archive**

## Use
Open `index.html` in any up-to-date browser, including from a local folder (file://). No server, account, external package, network call, CDN, cookie or service worker is required for the core interface. External source links require an internet connection. On small screens select ☰ for the module tree. Use `⌕ Search`, the route navigation, the investment modeling section and `Workspace` JSON backups. Print produces a complete report.

The interface uses HTML/CSS/vanilla JS in one file, with progressive no-JS reading. Theme and language navigation preferences may be saved locally. `FR*` translates menu labels only; policy content is in English until reviewed by a qualified Malagasy/French translator.

## Contents
- Government mandate, PGE-R and BNLTEH coordination
- Six modular interventions (P1–P6) connecting protection, safe labour mobility, WASH, school nutrition and regenerative enterprises
- Dated existing partner/funder programme registry with links and no presumption of endorsement
- Historical implementation evidence (Philippines, Moldova, Georgia, Belgium, Portugal, Brazil, Thailand and Madagascar)
- Interactive investment capital/risk scenarios and separately disclosed public grants
- Country/U.S./global on-ramps and copy/export partner brief
- Roadmap, prerequisites, audit metrics, rights safeguards
- IndexedDB local workspace with localStorage/in-memory fallback, versioned JSON backup and import
- Complete primary source ledger

## Finance limitations
All site-level budgets and scenario parameters are **illustrative proposals**, not committed funds or independently verified investment forecasts. Only lawful enterprise receipts count toward financial cashflows. Protection and essential social services are grant/public-financed and must never deliver investor dividends based on trafficking cases or survivor outcomes. Real diligence must include Malagasy law, eligible programme channels, taxes, FX, due process, community land and water rights, occupational health and safety, ecological impact and contracted demand.

The IRR model is nominal, simplified and unlevered; it omits actual financing costs, FX conversion, sectoral permits, detailed tax law and the full range of contract risks. “Scenario weights” are illustrative assumptions, not measured probabilities. Public/grant component is excluded from commercial investor cashflows. Do not use the demonstration as an offering document or investment advice.

## Sensitive information
Never enter survivor records, names, beneficiary addresses, complaints, health data or worker case files. Local storage is not encrypted and is not a secure case-management system. There is no telemetry, automatic sending or synchronization. Export before moving browsers or clearing device storage. Import prompts before replacement, validates version/schema and bounds file size. SHA-256 has not been presented as source authentication; trusted signatures and audited publication are needed for provenance when deployed.

## Deployment and testing
Upload `index.html` to any static host with HTTPS. Optional improvements for a hosted PWA: add a versioned separate service worker and manifest after auditing its cache behaviour; neither is appropriate as a `file://` dependency. For secure production adoption, maintain project-specific source/version control and conduct independent WCAG 2.2 AA, mobile keyboard/screen reader, security, legal, ecological, privacy and financing reviews.

### Suggested manual acceptance checks
1. Open from local file with internet disabled: routes, all content, search and finance simulation should work.
2. Toggle dark/light; navigate with keyboard and Escape; test mobile drawer and browser back/forward.
3. Change finance assumptions; check base/stress/upside outputs, NPV and yearly cashflows.
4. Save checkbox/notes, reload; export/import JSON; confirm corrupted/oversized imports are refused.
5. Print: all route sections should appear; source list should remain readable.
6. Check every external reference before institutional use and revalidate any live grant opportunity, contact and funding eligibility.
